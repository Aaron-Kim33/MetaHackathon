# Planned features

- **Conversational AI retouch:** The Retouch tool is reserved for voice/text instructions, result comparison and explicit user acceptance. This conversation UI and voice capture are not yet implemented. Existing asset repair/version reuse lives in the separate Library button below the main tools; moving it does not enable new AI calls.
- **3D+ — SAM 3D Objects:** Deferred at the user's request. Keep the current depth-based 3D preview. Revisit full object reconstruction once a suitable hosted integration is confirmed; Meta's web demo does not establish a supported app API or eligibility for the $150 Model API credits. No GPU provisioning, model downloads or inference calls are authorized by this roadmap entry.

# Editor labels

- The position tool is displayed as **편집 / Edit**.
- Canvas sticker selectors display **스티커 1 / Sticker 1**, etc., from the current sticker list in insertion order. Deleting a sticker closes numbering gaps; changing stacking order does not renumber them. Internal IDs and asset provenance remain stable.
