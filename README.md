# Reel Talk · Pop Out

AI 피사체 분리와 장식 생성을 결합한 독립 모바일 사진 편집툴입니다. 기본 편집·폰 팝아웃·투명 스티커는 편집 화면에서 선택하는 테마입니다. Meta Global AI Developer Hackathon의 **Build for Your World** 주제에 맞춰 개발합니다.

## 기여 범위

행사 전에 SNS 편집기 프로토타입과 제품 계획이 있었습니다. 이 저장소는 **2026-10-27에 새로 작성한 독립 구현**이며 기존 앱의 소스·이미지·계정 보관함을 포함하지 않습니다. 기존 코드베이스를 런타임 의존성으로 사용하지 않습니다. 일반 npm 라이브러리는 package.json과 잠금 파일에 명시합니다.

새 작업: 사진 정규화, 마스크 기반 피사체 합성, 직접 만든 휴대폰 프레임, 공통 좌표/출력 엔진, SAM/Muse API 어댑터, 영속 호출 예약, 최소 모바일 화면, 기기 초안 보관, 테스트용 벡터 그림과 검증 코드. 실제 API 및 휴대폰 검증 상태는 VALIDATION.md를 따릅니다.

3분 영상 첫 문장 초안(최종 구현 상태에 맞춰 조정):

> A basic mobile editor existed before the event. During this hackathon, we built the standalone SAM-powered pop-out compositor, Muse Image decoration workflow, and mobile demo shown here.

## 실행

Node.js 24, 같은 사설 Wi-Fi의 PC와 iPhone/Android, Expo Go가 필요합니다.

```powershell
cd "C:\Users\User\Desktop\META AI Hackathon\submission"
npm ci
npm start
```

`npm start`를 실행한 터미널에 QR이 표시됩니다. 터미널을 켜둔 채 휴대폰 Expo Go로 QR을 스캔하세요. 이 터미널에서 `r` 키로 연결된 앱을 새로고침할 수 있습니다. 같은 폴더의 다른 터미널에서 `npm run reload`를 실행해도 됩니다. 휴대폰 앱이 연결되기 전에는 새로고침을 보낼 대상이 없습니다.

Metro는 8082, 사진 합성 API는 4180을 사용합니다. QR을 Expo Go로 열면 PC 주소와 별도 연결 코드가 개발 설정에 전달됩니다. 자동 연결이 안 되면 앱 설정에 터미널의 서버 주소와 연결 코드를 입력하세요. 모델 API 키를 휴대폰에 입력하지 않습니다. 개발 서버가 켜진 동안 신뢰하는 로컬 네트워크에서만 사용합니다.

실행 시 `.local/expo-qr.png`에도 QR을 생성합니다. VPN/가상 어댑터를 제외한 LAN 주소를 우선 선택합니다. 네트워크가 여러 개면 `.env`의 `POPOUT_LAN_ADDRESS`로 PC에 실제 할당된 사설 IP를 지정할 수 있습니다.

키 없이 **연습용 그림**으로 합성·위치·비율·저장을 확인할 수 있습니다. 이 그림과 분리 레이어는 직접 만든 벡터 테스트 입력이며 SAM 결과가 아닙니다. 화면에 표시가 남습니다.

## 실제 Meta 모델 연결

대회 크레딧 신청·Billing·키 생성·터미널 설정·첫 실제 호출의 전체 순서는 [MODEL_API_CONNECT.md](MODEL_API_CONNECT.md)를 따른다. 2026-10-27 사용자가 공식 크레딧 신청폼 제출 완료를 알렸다. Billing 지급과 약관 전문은 아직 확인하지 않았으며 미확인 조건은 추정하지 않는다.

먼저 참가자 본인이 크레딧을 신청하고 Billing에 실제 지급·결제 설정·모델 권한이 반영됐는지 확인합니다. 모델 키는 로컬 비밀 입력으로 설정합니다.

```powershell
npm run setup:model
npm start
```

설정 명령은 숨김 입력으로 API 키와 사용자가 정한 **SAM/이미지 전체 호출 상한**을 submission/.env에 저장합니다. 기존 .env가 있으면 덮어쓰지 않습니다. 기본 상한은 0이며 설정 전에는 유료 호출을 차단합니다. 카드 등록이나 약관 동의·크레딧 신청을 대신 실행하지 않습니다.

설정 전에 Billing의 실제 $150 지급과 팀 일치를 확인해야 합니다. `HACKATHON_CREDITS_CONFIRMED=true`라는 수동 확인 기록이 없으면 유료 요청을 차단합니다. `npm run check:model`은 추론 없이 키와 모델 목록을 점검합니다. 키 설정 후에는 실행 중 서버를 Ctrl+C로 종료하고 `npm start`로 재시작해야 적용됩니다.

앱에서 설정 → 연결 확인 → 사진 선택 → 사진에서 대상 탭 또는 짧은 명사 입력 → SAM으로 분리 순서로 진행합니다. SAM 요청에는 정규화된 사진이 Meta로 전송됩니다. 후보가 여럿이면 선택합니다.

Muse Image 장식은 설명으로 생성한 다음 **생성한 장식 배경 분리**를 눌러 SAM으로 투명 에셋을 만듭니다. 전체 과정에 이미지 생성 1회와 SAM 1회가 필요합니다. 앞/뒤 배치와 위치·크기 변경은 추가 모델 호출을 하지 않습니다.

공식 연결:

- SAM: `sam-3.1`, `POST https://api.meta.ai/v1/responses`, [공식 안내](https://dev.meta.ai/docs/sam/overview)
- 마스크: `@meta-sam/parser@0.1.0`, [공식 파서](https://dev.meta.ai/docs/sam/client-libraries)
- 생성: `muse-image-1.0`, Responses API, [공식 안내](https://dev.meta.ai/docs/image-generation)

이 구현은 API 어댑터와 모의 제공자 테스트까지 완료한 상태이며, 키가 없는 상태에서 실제 모델 연결 성공을 주장하지 않습니다.

## 처리와 보관

- 편집 화면은 스크롤 페이지 대신 **고정 캔버스 + 오른쪽 도구 + 접히는 하단 패널**입니다. 사진·피사체·위치·장식·테마·더보기로 묶었으며, 저장·실행 취소는 상단, 원본 비교·공유는 하단에 고정합니다. 길어진 도구 내용만 패널 안에서 스크롤합니다.
- **위치**는 위치·크기/그림자/비율, **장식**은 만들기/배치로 나눕니다. **더보기**에 연결 설정·AI 작업 상태를 모았습니다. Android 뒤로 가기는 선택 화면이나 열린 패널을 먼저 닫습니다.

- 사진은 EXIF 방향을 적용하고 최대 1600px로 정규화합니다. 박스·마스크는 이 이미지 좌표를 사용합니다.
- 원본과 피사체에 동일한 확대·이동을 적용합니다. 사진 위에서 한 손가락 이동·두 손가락 확대를 바로 사용할 수 있습니다. 조절 중 휴대폰에서 즉시 미리보기를 그리며, 손을 놓으면 최종 합성 PNG를 갱신합니다. 숫자 도구는 하단 **변경 적용**으로 확정합니다. 조절 중 그림자는 최종 합성 때 정밀하게 반영되며, 저장 파일은 확정된 PNG입니다.
- 하단 **원본**을 누르고 있으면 사진과 결과를 비교합니다. **피사체 → 누끼 다듬기**는 같은 화면의 캔버스를 보정 영역으로 전환해 지우기 브러시·크기 조절·한 획 취소·보정 적용을 제공합니다. **누끼 보정 초기화**를 한 번 누르면 처음 분리된 누끼로 돌아갑니다. 사용자 요청에 따라 복원 브러시는 화면에서 제외했습니다. 이 직접 편집은 모델을 다시 호출하지 않습니다.
- 4:5는 1080×1350, 9:16은 1080×1920, 1:1은 1080×1080입니다. 프레임은 직접 렌더링합니다.
- 개발 API의 `.local/projects`에 원본·피사체·장식·보정 이력과 설정을 보관합니다. 휴대폰에는 마지막 캔버스·원본·스티커·미적용 편집값을 교대 저장하고, 백그라운드로 갈 때도 저장을 시도합니다. 마지막 결과는 기기에 남습니다. 현재 개발 단계의 재편집 요청은 로컬 API 연결이 필요하며, 일반 사용자용 서버 배포는 아직 수행하지 않았습니다. 사용자의 제작·편집·저장·공유 동작은 모바일 앱 안에서 제공합니다.
- 전체 호출 상한은 `.local/model-jobs.json`의 영속 예약을 기준으로 적용합니다. 처리 중이거나 결과 미확인인 호출도 상한에 포함하며 자동 재시도하지 않습니다. 같은 작업 ID는 성공 결과를 재사용합니다.
- 호출 횟수 제한은 **계정 잔액·달러 예산·제공자 전체 사용량 측정이 아닙니다.** 제공자 Billing을 별도로 확인합니다. 기록 파일을 지워 제한을 초기화하지 않습니다.
- 서버는 한 사용자·한 프로세스 개발용입니다. 공개 배포·다중 사용자 인증·클라우드 백업을 구현한 상태가 아닙니다.

## 현재 제약

실제 SAM/Muse 응답·머리카락 품질·새 터치 조작과 브러시의 기기 사용감·앨범/공유는 아직 검증하지 않았습니다. 장식 재표시, MP4, 영상 추적, SNS 직접 게시와 오픈 모델 통합은 현재 범위에 포함되지 않습니다. 그림에서 조절 가능한 UI는 실제 사진 검증을 대체하지 않습니다.

기존 개발 서버가 새 보정 API를 아직 반영하지 않았다면 한 번 **Ctrl+C → npm start**로 재시작합니다. 이후 화면 변경은 앱을 연 상태에서 터미널 `r` 또는 `npm run reload`로 반영합니다. 오른쪽 **사진 → 연습용 그림**으로 시작하면 Meta 키 없이 터치 조절·패널·원본 비교·누끼 보정을 사용할 수 있습니다.

후속 기기 확인: 사용자가 기존 연습용 합성과 숫자 조절 동작을 확인했습니다. 앨범 저장의 SDK 58 구형 API 오류는 `Asset.create`로 수정했으나, 사용자 기기에서 Expo Go 권한 제한이 확인돼 저장 검증은 보류했습니다. 새 터치 조작과 누끼 브러시는 별도 기기 재확인이 필요합니다.

## 제출 준비

- 행사 중 개발한 코드만 포함한 이 폴더를 공개 저장소로 준비합니다. `.env`, `.local`, `node_modules`, 개인 사진·키를 포함하지 않습니다.
- 저장소를 내려받은 뒤 `npm ci`로 실행할 수 있는지 확인합니다.
- 실제 사진과 모델 결과로 3분 영상을 만들고 첫 문장에서 사전 작업을 밝힙니다.
- [제출 페이지](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/hackathon/submit)에 공개 코드·영상·참가자 전원을 기재합니다. 마감은 MYT 2026-11-05 10:00, 내부 목표는 11-04 18:00입니다.
- 운영진의 standalone extract 지침에 맞춰 기존 코드베이스를 제외했습니다. 개별 참가 자격과 최종 제출 폼 요건은 별도 확인해야 합니다.

## 테마와 테두리 자르기

피사체 → 테두리로 자르기에서 남길 영역을 한 바퀴 그린 뒤 자르기 적용을 누릅니다. 끝점은 자동으로 연결되며 새로 그리면 이전 테두리를 교체합니다. AI 없이 원본 픽셀과 투명 알파로 자르며 선택한 테마와 위치는 유지합니다. 오른쪽 테마에서 기본 편집·폰 팝아웃·투명 스티커를 고릅니다. 새 사진은 기본 편집으로 시작합니다. 폰 팝아웃은 원본 프레임과 튀어나온 피사체·그림자를 합성하고, 투명 스티커를 고르면 원본/폰 프레임 없이 피사체만 드래그·핀치합니다. 체크무늬는 투명 영역 안내이며 PNG에 포함되지 않습니다. 지우개 보정은 별도 도구이고 초기화는 선택한 스티커의 보정만 되돌립니다. 폰 프레임 모드에서 지운 전경은 아래 원본 사진에서도 다시 드러나지 않게 합니다.

이번 변경은 API 경로도 추가하므로 기존 npm start 터미널에서 Ctrl+C 후 npm start로 재시작해야 합니다. 단순 앱 새로고침으로는 실행 중 API 코드가 갱신되지 않습니다.

## 같은 캔버스에 스티커 추가

첫 사진은 작업을 시작하고, 이후 사진 → 사진 추가는 현재 작업에 원본을 가져옵니다. 테두리로 자른 피사체는 독립 스티커로 추가되며 기존 사진·피사체·스티커·테마는 유지합니다. 가져온 사진은 사진 패널에서 AI로 분리해 스티커로 추가할 수도 있습니다. 캔버스에서 스티커를 터치한 뒤 드래그·핀치하고, 피사체/위치 패널에서 기본 사진과 개별 스티커를 선택하거나 맨 앞으로/선택 삭제를 사용할 수 있습니다. 지우개 보정과 초기화도 선택한 스티커에만 적용됩니다. 스티커는 최대 16개이며 각각 위치·크기·순서를 보관합니다.

최근 작업 목록과 작업 전환 UI는 제거했습니다. 마지막 캔버스·미적용 조절값·선택한 스티커·미확인 모델 작업을 기기에 자동 보관하며, 이전 형식의 프로젝트 목록은 새 스냅샷에 포함하지 않습니다. 두 개의 교대 저장 파일은 같은 마지막 편집의 손상 대비용입니다. 기존 다른 작업 파일을 자동 삭제하지 않습니다.

폰 팝아웃은 기울기·폰 옆면 두께·금속 테두리·접촉/분리 그림자를 강화했습니다. 위치 → 그림자에서 기울기와 깊이를 조절합니다. 프레임의 기울기는 공유 PNG와 미리보기에 적용되며, 터치 이동은 역변환해 좌표를 맞춥니다. 실제 입체 메시를 생성하는 기능은 아닙니다.
